# 文档3：核心模块详细设计文档
## 1. SDK Facade模块
### 1.1 核心类
- PlayerView：绑定View生命周期，渲染载体
- Player：对外控制入口（play/pause/seek/export）
- Clip：音视频片段/动画片段封装
- Config：渲染/编码参数配置
### 1.2 生命周期
onCreate→init→onResume→start→onPause→pause→onDestroy→release

## 2. Runtime模块
### 2.1 播放状态机
状态流转：Idle → Prepared → Playing → Paused → Seeking → Stopped → Idle
### 2.2 Timeline调度
按当前时间t计算：帧索引、图层可见性、特效参数
### 2.3 JNI Bridge
方法：initEngine、releaseEngine、sendTimelineTick、setEffectParam

## 3. Native Engine模块
### 3.1 解码模块
MediaCodec解码→SurfaceTexture→OES纹理上传
### 3.2 纹理管理
OES纹理池、普通纹理池、FBO池复用
### 3.3 RenderGraph
渲染通道：调色→羽化→阴影→转场→合成
### 3.4 图层合成
按固定顺序执行混合、变换、透明度计算
### 3.5 时钟同步
AudioClock获取时间戳，控制帧提交时机
### 3.6 导出模块
离屏渲染→编码输入→封装MP4

## 4. Shader特效模块
### 4.1 顶点Shader
通用全屏四边形顶点
### 4.2 片段Shader
- 调色Shader：brightness/contrast/saturation/temperature
- 羽化Shader：alpha边缘平滑
- 阴影Shader：投影偏移+模糊
- 转场Shader：mask混合控制
