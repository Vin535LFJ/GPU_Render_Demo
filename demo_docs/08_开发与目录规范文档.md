## 2. 编码规范
### Kotlin
- 命名：驼峰式，类名大写，方法小写
- 空安全：强制使用?/!!
- 函数：单一职责，长度≤50行

### C++
- 标准：C++17
- 内存：智能指针，禁止裸指针
- 线程：GL操作单线程

### GLSL
- 版本：#version 300 es
- 命名：小写+下划线
- 统一变量：u_前缀，属性：a_前缀，纹理：s_前缀

## 3. 版本与工具链矩阵（冻结）
- C++：C++17（强制）
- Kotlin：与AGP版本兼容矩阵锁定（由构建配置统一维护）
- AGP：固定主版本线（由构建配置统一维护）
- NDK：固定主版本线（由构建配置统一维护）

> 约束：版本升级必须先通过Stage冻结评审，不得在实现期临时升级。

## 4. 线程规范（冻结）
### 4.1 Owner职责
- UI线程：只发控制命令，不直接操作GL/EGL/Codec
- Runtime控制线程：状态迁移校验与命令编排
- DecodeThread：MediaCodec dequeue/flush/seekTo
- RenderThread：EGL/GL/SurfaceTexture及render submit

### 4.2 禁止项
- 非RenderThread调用 `eglMakeCurrent` / `updateTexImage` / SurfaceTexture attach-detach
- 非DecodeThread调用 MediaCodec `flush/dequeue`
- 非Runtime控制线程直接改状态机状态

### 4.3 失败策略
- 违反线程owner约束：返回 `E_RUNTIME_CONTRACT_BREACH`
- fatal违规：进入 stop/release 收口路径，禁止继续渲染提交
