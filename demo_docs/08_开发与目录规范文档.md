## 2. 编码规范
### Kotlin
- 命名：驼峰式，类名大写，方法小写
- 空安全：强制使用?/!!
- 函数：单一职责，长度≤50行

### C++
- 标准：C++17
- 内存：智能指针，禁止裸指针
- 线程：GL操作单线程

### GLSL
- 版本：#version 300 es
- 命名：小写+下划线
- 统一变量：u_前缀，属性：a_前缀，纹理：s_前缀
