## 1 项目概述
### 1.1 项目定位
本项目为 **Android 平台 GPU 原生音视频特效编辑原型 Demo**，聚焦硬解、GPU 渲染、时间线特效、音视频同步、离屏导出全链路验证，不做完整 NLE 编辑器与重型 AI 特效，为后续 SDK 化提供技术基准与可复用架构。

### 1.2 核心价值
1. 验证 `MediaCodec → SurfaceTexture → OES 纹理 → GL 渲染` 链路可行性
2. 实现**音频主时钟**驱动的音视频+帧动画统一同步
3. 预览/导出复用 `RenderGraph`，彻底解决**所见非所得**问题
4. 支持 1080p 稳定运行，4K 提供可控降级策略

### 1.3 技术约束
- 平台：Android 12+，兼容业务指定 minSdk
- 渲染：OpenGL ES 3.0/3.2
- 编解码：MediaExtractor + MediaCodec
- 导出：MediaCodec Encoder + MediaMuxer
- 开发语言：Kotlin + JNI + C++11

## 2 需求规格说明
### 2.1 功能需求
1. **视频纹理化播放**
   MediaCodec 硬解输出到 SurfaceTexture，转换为 OES 外部纹理，GL 渲染显示；支持播放/暂停/seek/停止。
2. **2D 帧动画多层合成**
   合成顺序：`Background → Back FX → Shadow → Character → Front FX → Overlay`；支持变换、透明度、混合模式、时间区间可见。
3. **音视频时钟同步**
   音频为主时钟，无音频回退单调时钟；小偏差调速、大偏差丢帧/追帧。
4. **Shader 特效链**
   基础调色（亮度/对比度/饱和度/色温）、边缘羽化、阴影、淡入淡出/滑动遮罩转场；支持参数实时调节。
5. **离线导出**
   离屏 FBO 渲染，H.264/H.265+AAC 封装 MP4；支持进度回调与取消。
6. **状态与统计**
   播放状态机管理；帧耗时、FPS、缓存命中率、延迟帧比例可观测。

### 2.2 非功能需求
- 性能：1080p 30/60fps 稳定，4K 支持动态降级
- 稳定性：长时间播放无内存泄漏，高频 seek 无黑屏/崩溃
- 兼容性：兼容主流 Android 机型与 OpenGL ES 版本
- 可扩展性：Shader 特效、图层类型可灵活扩展

### 2.3 需求边界（本期不实现）
- 完整 NLE 编辑器、海量模板系统
- Vulkan 渲染首版实现
- 美颜、分割、超分等重型 AI 特效

## 3 系统架构设计
### 3.1 总体架构（三层分层）
采用 **SDK Facade → Runtime → Native Engine** 三层架构，职责隔离、解耦、可扩展。
1. **SDK Facade（Kotlin）**
   对外 API 入口，生命周期绑定，业务唯一交互层。
2. **Runtime（Kotlin + JNI）**
   时间线调度、播放状态机、资源编排、Native 桥接。
3. **Engine Core（C++）**
   OpenGL 渲染内核、纹理/FBO 管理、RenderGraph、编解码、导出、时钟同步。

### 3.2 模块依赖关系

App → SDK Facade → Runtime → JNI Bridge → Native Engine

### 3.3 核心流程架构
- 实时预览：`AudioClock → TimelineTick → LayerResolve → RenderGraph → Present`
- 离线导出：`ExportClock → TimelineTick → Offscreen RenderGraph → EncoderSurface → MediaMuxer`

## 4 核心模块详细设计
### 4.1 SDK Facade 模块
- 核心类：PlayerView、Player、Clip、Config、PlayerCallback
- 职责：对外暴露控制接口，绑定 Activity/Fragment 生命周期
- 生命周期：`onCreate → init → onResume → play → onPause → pause → onDestroy → release`

### 4.2 Runtime 模块
1. **播放状态机**
   流转：`Idle → Prepared → Playing → Paused → Seeking → Stopped → Idle`
2. **Timeline 调度**
   按当前时间 t 计算帧索引、图层可见性、特效参数。
3. **JNI Bridge**
   Kotlin↔C++ 方法调用、数据传递、引擎句柄管理。

### 4.3 Native Engine 模块
1. 解码模块：MediaCodec 解码 → SurfaceTexture → OES 纹理上传
2. 纹理/缓存模块：纹理池/FBO 池复用，LRU 缓存
3. RenderGraph 模块：调色→羽化→阴影→转场→合成多 Pass 执行
4. 图层合成模块：按序执行变换、混合、透明度计算
5. 时钟同步模块：AudioClock 提供时间基准
6. 导出模块：离屏渲染→编码→封装 MP4

### 4.4 Shader 特效模块
- 顶点 Shader：通用全屏四边形顶点处理
- 片段 Shader：调色、羽化、阴影、转场四类核心 Shader

## 6 音视频同步与渲染流程

### 6.1 时钟同步策略

- 主时钟：默认 AudioClock，无音频使用系统单调时钟

- 同步规则：

  1. 视频帧按 PTS 对齐主时钟
  2. 动画帧按时间 t 直接计算索引
  3. 偏差＜50ms：微调播放速率
  4. 偏差＞100ms：丢帧 / 追帧

  

### 6.2 实时预览流程

1. AudioClock 获取当前播放时间 t
2. Timeline 解析 t 对应的帧、图层、特效参数
3. 解码器输出帧到 SurfaceTexture
4. 转换为 OES 外部纹理
5. RenderGraph 执行多 Pass 渲染
6. 合成结果渲染到屏幕

### 6.3 离线导出流程

1. 启动固定步进 ExportClock
2. 逐帧触发 Timeline Tick
3. 离屏 FBO 执行渲染
4. 帧数据送入编码器 Surface
5. 音视频数据封装为 MP4

### 6.4 Seek 处理流程

1. 停止渲染帧提交
2. Flush 解码器与纹理队列
3. 定位到视频关键帧
4. 重置 Timeline 时间指针
5. 恢复渲染循环

## 7 性能与稳定性设计

### 7.1 性能预算

- 1080p：渲染耗时 ≤16ms (30fps)/≤8ms (60fps)，解码 ≤10ms，延迟帧比例 ≤1%
- 4K 降级：降低 FBO 分辨率、关闭高阶特效、减少层数、强制 1080p 导出

### 7.2 内存管理规范

1. 纹理 / FBO 使用对象池，禁止每帧创建销毁
2. LRU 缓存 + 水位线控制，超量自动回收
3. GL 线程禁止磁盘 I/O 与重型解析
4. 退出时完整释放所有 GL 资源

### 7.3 稳定性保障

1. Seek 必须 flush 解码器，清空纹理队列
2. 状态机严格校验，禁止非法跨状态调用
3. JNI 调用全量异常捕获
4. 长时间播放定时内存巡检

### 7.4 监控指标

FPS (P50/P95)、渲染 / 解码 / 上传耗时、延迟帧比例、缓存命中率、内存峰值

## 10 核心流程 / 时序 / 类图（文字描述）

### 10.1 流程图

1. 实时预览流程

   开始→引擎初始化→创建 AudioClock→启动解码器→帧解码→OES 纹理转换→Timeline Tick→RenderGraph 渲染→上屏→循环 / 结束

2. 离线导出流程

   开始→导出配置→创建 ExportClock→创建离屏 FBO→逐帧渲染→编码→封装→MP4 写入→进度回调→完成 / 取消→释放资源

3. Seek 流程

   暂停→停止渲染→Flush 解码器→清空纹理→定位关键帧→重置 Timeline→恢复渲染→继续播放

### 10.2 时序图

1. 播放控制时序

   App→PlayerView→Player→JNI→NativeEngine→Decoder→MediaCodec→Prepared→play→AudioClock→RenderGraph→上屏

2. 导出时序

   App→Player→Runtime→NativeEngine→离屏渲染→编码器→MediaMuxer→MP4→进度回调→完成

### 10.3 类图

1. **SDK Facade**：PlayerView、Player、Clip、ExportConfig、PlayerCallback
2. **Runtime**：Timeline、PlayerStateMachine、JniBridge
3. **Native Engine**：NativeEngine、Decoder、TextureManager、RenderGraph、LayerComposer、AudioClock、Exporter

## 12 风险与 Mitigation

| 风险           | 影响             | 缓解方案                          |
| -------------- | ---------------- | --------------------------------- |
| OES 纹理兼容性 | 部分机型渲染异常 | 兼容 OpenGL ES 3.0+，增加降级逻辑 |
| 4K 性能不足    | 卡顿、掉帧       | 动态分辨率 + 降效 + 降层策略      |
| 音画不同步     | 体验差           | 音频主时钟 + 偏差修正 + 帧控制    |
| 内存泄漏       | 长时间播放崩溃   | 池化复用 + 主动释放 + 内存巡检    |

## 13 附录

### 13.1 缩写说明

- OES：OpenGL ES External Texture
- FBO：Frame Buffer Object
- RenderGraph：渲染通道图
- Timeline：时间线
- PTS：Presentation Time Stamp

### 13.2 术语说明

- 时间线特效：按时间区间触发的图层 / 特效控制
- 离屏渲染：不直接上屏，渲染到 FBO 用于编码导出
- 所见即所得：预览与导出使用同一套渲染逻辑
