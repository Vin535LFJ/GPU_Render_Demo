# 文档5：性能与稳定性设计规范
## 1. 性能预算
### 1.1 1080p预算
- 单帧渲染耗时：≤16ms（30fps）/≤8ms（60fps）
- 解码耗时：≤10ms
- 纹理上传：≤3ms
- 延迟帧比例：≤1%

### 1.2 4K降级策略
1. 降低FBO分辨率
2. 关闭高阶特效（阴影/高精度羽化）
3. 减少同时渲染层数
4. 强制1080p导出

## 2. 内存规范
1. 纹理/FBO使用对象池，禁止每帧创建销毁
2. LRU缓存，设置水位线，超量自动回收
3. GL线程禁止I/O、解析操作
4. 退出时完整释放所有GL资源

## 3. 稳定性规范
1. Seek时必须flush解码器，清空纹理队列
2. 状态机严格校验，禁止跨状态非法调用
3. 所有JNI调用加异常捕获
4. 长时间播放定时内存巡检

## 4. 监控指标
- FPS（P50/P95）
- 渲染/解码/上传耗时（P50/P95）
- 延迟帧比例
- 缓存命中率
- 内存峰值
