# 文档6：音视频同步与渲染流程设计文档
## 1. 时钟同步策略
### 1.1 主时钟
- 默认：AudioClock（音频播放时间戳）
- 无音频：System monotonic clock

### 1.2 同步规则
1. 视频帧按PTS对齐主时钟
2. 动画帧按时间t直接计算索引
3. 偏差<50ms：微调播放速率
4. 偏差>100ms：丢帧/追帧

## 2. 实时预览流程
1. AudioClock获取当前时间t
2. Timeline计算t对应的帧/图层/特效
3. 解码器输出帧到SurfaceTexture
4. 转换为OES纹理
5. RenderGraph执行多Pass渲染
6. 合成结果上屏

## 3. 离线导出流程
1. 启动固定步进ExportClock
2. 逐帧tick时间线
3. 离屏FBO渲染
4. 帧数据送入编码器
5. 音视频数据封装为MP4

## 4. Seek流程
1. 停止渲染提交
2. Flush解码器与纹理队列
3. 定位到关键帧
4. 重置Timeline指针
5. 恢复渲染循环
