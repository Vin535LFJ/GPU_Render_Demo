# 文档1：项目需求规格说明书（SRS）
## 1. 项目概述
### 1.1 项目名称
Android音视频特效编辑Demo（GPU Native）
### 1.2 项目定位
基于MediaCodec+OpenGL ES的音视频实时预览+离线导出原型，验证GPU特效渲染与时间线同步闭环。
### 1.3 目标用户
Android音视频开发工程师、SDK集成开发者

## 2. 功能需求
### 2.1 视频纹理播放
- 支持MediaCodec硬解输出到SurfaceTexture
- 支持OES外部纹理渲染显示
- 支持播放/暂停/seek/停止控制
### 2.2 多层合成
- 合成顺序：Background→BackFX→Shadow→Character→FrontFX→Overlay
- 支持图层位置/缩放/旋转/透明度/混合模式控制
- 支持图层时间区间可见控制
### 2.3 音视频同步
- 音频主时钟驱动，无音频 fallback 单调时钟
- 支持小偏差调速、大偏差丢/追帧
### 2.4 Shader特效
- 基础调色：亮度/对比度/饱和度/色温
- 边缘羽化、投影阴影
- 转场：淡入淡出、滑动遮罩
### 2.5 离线导出
- 离屏FBO渲染，预览导出同逻辑
- 输出H.264/H.265+AAC MP4
- 支持进度回调与取消
### 2.6 状态与统计
- 播放状态机：Idle/Prepared/Playing/Paused/Seeking/Stopped
- 帧耗时、FPS、缓存命中率、延迟帧统计

## 3. 非功能需求
### 3.1 性能
- 1080p：30/60fps稳定
- 4K：支持动态分辨率/降效/降层降级
### 3.2 稳定性
- 7×24h播放无内存泄漏
- 高频seek无黑屏、崩溃、花屏
### 3.3 兼容性
- 最低版本：业务指定minSdk，优先Android12+
- 兼容OpenGL ES3.0/3.2

## 4. 需求边界
### 4.1 本期实现
见2.1-2.6功能
### 4.2 本期不实现
- 完整非线性编辑（NLE）、模板系统
- Vulkan渲染
- 重型AI特效（美颜/分割/超分）
