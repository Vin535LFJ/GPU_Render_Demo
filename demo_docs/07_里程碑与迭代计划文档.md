# 文档7：里程碑与迭代计划文档
## 1. 总目标
MVP→可演示Demo，验证全链路闭环

## 2. 里程碑规划
### M1：工程骨架（1周）
- 输出：SDK模块+Sample App、JNI初始化、GL渲染循环
- 验收：工程可编译、GL窗口可显示

### M2：视频纹理化播放（1~2周）
- 输出：MediaCodec解码、OES渲染、播放/暂停/seek
- 验收：1080p视频正常播放无花屏

### M3：多层帧动画合成（1~2周）
- 输出：图集加载、图层按序合成、时间线控制
- 验收：多图层正确叠加

### M4：音视频时钟同步（1周）
- 输出：AudioClock、漂移修正
- 验收：音画无明显延迟

### M5：Shader特效链（1~2周）
- 输出：调色/羽化/阴影/转场
- 验收：特效实时生效

### M6：离线导出（1~2周）
- 输出：离屏渲染、编码、封装
- 验收：导出MP4与预览一致

### M7：性能优化（持续）
- 输出：性能监控、4K降级、内存优化
- 验收：1080p稳定60fps

## 3. 验收标准
1. 功能：全链路可用
2. 性能：1080p 30/60fps稳定
3. 稳定性：无泄漏、无崩溃
