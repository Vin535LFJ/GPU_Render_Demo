# Stage Scope Definition

## Stage 0 (Freeze Backport)
- In scope:
  - 00–08 与 09/10 的 runtime 行为对齐
  - 冲突识别、合同化表达、验收口径冻结
- Out of scope:
  - 功能设计新增
  - 架构扩展
  - implementation task 拆解与编码

## Stage 1 (Freeze Validation)
- In scope:
  - 文档一致性验证
  - runtime contract可验证性检查
- Out of scope:
  - 编码、特效实现、导出实现

## Stage 2 (Readiness Gate)
- In scope:
  - blocker清零决策
  - milestone exit condition 复核
- Out of scope:
  - 开始功能开发

## Stage 3 (Controlled Execution Start)
- 仅定义进入条件，不在当前阶段执行。
